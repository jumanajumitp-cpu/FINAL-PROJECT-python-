# Obesity Level Analysis Based on Eating Habits and Lifestyle Factors

## Project Overview

This project focuses on analyzing obesity levels and exploring the relationships between eating habits, physical activity, and lifestyle factors using Python.

The aim is to identify patterns and trends in the dataset through data cleaning, Exploratory Data Analysis (EDA), statistical analysis, and data visualization.

## Objectives

- Analyze different obesity levels in the dataset.
- Explore the relationship between obesity levels and eating habits.
- Examine the impact of physical activity and lifestyle patterns.
- Identify patterns and relationships among demographic and health-related factors.
- Present meaningful insights through data visualization.

## Dataset

The project uses an obesity dataset containing demographic, eating habit, and lifestyle-related information.

**Dataset details:**
- Total records after cleaning: 2,087
- Total columns after preparation: 20
- Duplicate records removed: 24

## Tools and Technologies

- **Python** – Data analysis and processing
- **Pandas** – Data manipulation and cleaning
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Plotly** – Interactive visualizations
- **Jupyter Notebook** – Development environment

## Project Workflow

### 1. Data Cleaning and Preparation
- Explored the dataset using `head()`, `tail()`, and `info()`.
- Removed 24 duplicate records.
- Standardized column names and categorical values.
- Converted selected columns into appropriate data types.
- Created additional columns such as BMI, Age Group, BMI Category, and Lifestyle Activity Level.
- Removed the MTRANS column from the analysis.

### 2. Exploratory Data Analysis (EDA)
- Performed descriptive statistical analysis.
- Used GroupBy and pivot tables.
- Explored numerical and categorical variables.
- Conducted correlation analysis.
- Examined relationships between obesity levels, eating habits, and lifestyle factors.

### 3. Data Visualization
Created 20 visualizations using Matplotlib, Seaborn, and Plotly to explore patterns and relationships in the dataset.

Visualization techniques included:
- Bar charts
- Line charts
- Pie charts
- Histograms
- Box plots
- Scatter plots
- Heatmaps
- Interactive visualizations

## Key Analytical Insights

- Obesity Type I was the largest individual obesity category in the analysis.
- A strong positive relationship was observed between body weight and BMI.
- Physical activity levels varied across different obesity categories.
- Eating habits and other lifestyle factors showed different patterns across obesity levels.

## Conclusion

This project helped explore obesity levels and their relationships with eating habits, physical activity, and lifestyle factors. Through Python-based data cleaning, EDA, statistical analysis, and visualization, meaningful patterns and insights were identified.
